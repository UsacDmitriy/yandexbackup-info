Privacy policy

Effective date: 20 October 2026.

YandexBackup is operated by its owner for personal backup use. It accesses source files selected by the owner and creates or maintains authorized copies in the owner's Google Drive. File names, directory paths, sizes, timestamps and supported checksums are used to organize and verify those copies.

Google receives the files and metadata required to store the authorized backups. Source services receive the requests needed to read the selected source data. Transfer work runs on the owner's Mac; there is no separate public backup server operated by this application.

Application credentials, authorization tokens and operational logs are stored in private local files outside the cloud backup folders. The backup workflow excludes its credentials and configured sensitive service files from copied content.

The application does not sell Google user data, use it for advertising, send documents to external AI models, or intentionally share backup files with other people. Google Drive sharing settings remain under the owner's control.

Backup copies and previous versions are retained until the owner chooses otherwise. Revoking the application's Google access stops future authorized API operations; it does not automatically delete existing backup files. The owner can manage or delete those files directly in Google Drive.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
